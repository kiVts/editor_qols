# Editor QOLs

[![Join Discord](https://img.shields.io/badge/Join-Discord-5865F2?style=for-the-badge&logo=discord&logoColor=white)](https://discord.gg/bX4RzunsxC)

A few quality-of-life additions for the vehicle editor. Each one can be turned off on its own in the mod's settings.

**Smart Piping:** when you place a pipe next to another pipe, the neighbor changes into the right T, corner or cross piece, so the two connect. You can also place pipes onto the side of a pipe that has no opening there; the mod reshapes it for you. Paint is kept, it works with the symmetry tool and with drag placement, and Ctrl+Z / Ctrl+Y undo it like any other edit. Hold Left Alt to place a pipe without connecting it.
There are intentional limitations to prevent confusion: deleting a pipe manually will not plug the connection it leaves behind, and other changes like that are not made.

**Settings Copy:** Copy and Paste buttons in the editor's top bar copy every setting of the selected block and paste them into another block of the same type, for example all the instruments of an instrument panel. Ctrl+C / Ctrl+V press the buttons, and Ctrl+Z / Ctrl+Y undo a paste. Pasting into different types of blocks will not work, even if they share some settings.

To use, install [SWML](https://github.com/kiVts/swml) and add the zip from releases here. I also recommend you install [No Crash Uploads](https://github.com/kiVts/no_crashlog_upload) so you don't upload a crash report with an injected DLL to Geometa (a crash is overwhelmingly likely to be due to one of these mods). Consider other mods as well!
